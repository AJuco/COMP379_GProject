# COMP 379 - Group Project

## Our Dataset

We are using the Sleep Health and Lifestyle Dataset that can be found on Kaggle:

- https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset/

The target we are predicting is type of sleep disorder. The possible outcomes are insomnia, sleep apnea, and no disorder, and we will be using the features provided to make our predictions.

### Dataset Features

We are using the following features to make our predictions. The Person ID feature is excluded because we believe that it is not useful for analysis.

- Gender
- Age
- Occupation
- Sleep Duration
- Quality of Sleep
- Physical
- Stress Level
- BMI Category
- Blood Pressure
- Heart Rate
- Daily Steps
